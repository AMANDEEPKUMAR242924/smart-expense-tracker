# Smart Expense & Budget Tracker

A full-stack MERN web application to track daily income and expenses, visualize category-wise spending with interactive charts, and manage personal finances securely with JWT authentication.

## Tech Stack
- **Frontend:** React (Vite), Tailwind CSS, Recharts, Axios, Lucide Icons
- **Backend:** Node.js, Express.js, JWT Authentication, bcryptjs
- **Database:** MongoDB Atlas (Mongoose)
- **Deployment:** Vercel (Frontend) & Render (Backend)

## Key Features
- Secure user registration and login using JWT and password hashing
- Real-time calculation of Total Balance, Total Income, and Total Expense
- Category-wise interactive Pie Chart analytics using Recharts
- Filter transactions by type (Income / Expense) and delete entries
- User-isolated data access via protected REST API routes
